# AGENTS.md

`crossy-code` is a Claude Code plugin. `/crossy-code` opens a pane with a Crossy Road style game,
drawn in the terminal by a small software renderer. The repository is also a single-plugin
marketplace (`.claude-plugin/marketplace.json`, `source: "./"`).

## The parody

| Crossy Road | Crossy Code |
| --- | --- |
| Chicken | Clawd, or a character bought with tokens |
| Cars and trucks | Bugs: ladybug, beetle, cockroach, centipede |
| Train | The merge train: an engine and 3 to 5 CI result cars (passing, failing, pending) |
| River, logs, lily pads | A stream to `/dev/null`, with logs and lily pads |
| Trees and rocks | Dependency trees hung with packages, server racks, shipping boxes, rocks |
| Coins | Tokens |
| The eagle | The cursor, which takes anyone who idles |

Deaths and their banners: squashed by a bug `SEGFAULT`, hopped into one `RACE CONDITION`,
the train `MERGE CONFLICT`, drowned `/DEV/NULL`, carried off screen by a log `OUT OF BOUNDS`,
the cursor `SIGKILL`. `deathBanner` and `deathLine` in `hooks/scene.ts` hold the words.

## Layout

| File | What it does |
| --- | --- |
| `hooks/register.tsx` | The command, the pane, keys, the frame loop, the save, the character picker |
| `hooks/keys.tsx` | `Client` module for the status line; posts arrow and h j k l keys back |
| `hooks/game.ts` | Rules and world generation, seeded with mulberry32 |
| `hooks/render.ts` | Software renderer: boxes in, Raster cells out |
| `hooks/scene.ts` | Game state to draw calls; HUD, title, banners, picker |
| `hooks/models.ts` | Voxel models, as boxes in sixteenths of a tile |
| `hooks/font.ts` | 5x7 pixel font |
| `types/index.d.ts` | `CrossyUi`, `CrossySave`, and the `PluginState` contract |

## Things to keep

- **Color pairs.** The terminal paints at most 1024 (foreground, background) pairs a frame.
  `encode()` rounds to 4 bits a channel and `budgetPairs()` keeps 1000. Don't raise `PAIR_BUDGET`.
- **The hooks runtime interprets, it doesn't compile.** The renderer's inner loops inline their
  math and reuse typed arrays. Don't split them into helpers or vector objects. Frame budget: 33 ms.
- **Blits.** At most 2 in flight. A blit with `deny` means the pane is gone: stop the loop and pause.
- **Raster is terminal only.** Other surfaces get a text fallback.
- **Generation leaves a way through.** Each grass row is checked with `reachable()`. The
  "every grass row leaves a way through" test covers 40 seeds of 300 rows.
- `.claude-plugin/types/` is generated by the plugin tooling. Don't write or commit it.

## Checking changes

```
claude plugin validate .
claude plugin test .
```

Test the look in a truecolor terminal. In tmux, set `COLORTERM=truecolor` and
`set -as terminal-features ',*:RGB'`.
